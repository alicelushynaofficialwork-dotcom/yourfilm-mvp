# YourFilm MVP

YourFilm — это MVP ИИ-платформы рекомендаций фильмов, где первый продуктовый сценарий простой и понятный:

1. Пользователь выбирает свое эмоциональное состояние.
2. YourFilm рекомендует фильм.
3. Приложение объясняет, почему этот фильм подходит под настроение, какую эмоцию он может дать, чему можно научиться у героя и как фильм помогает иначе посмотреть на ситуацию.

## Технологии

- React + Vite
- Локальная база фильмов для первой версии MVP
- Локальный механизм рекомендаций
- Позже: Supabase, OpenAI API, TMDB API

## Состав первой версии MVP

- Главная страница
- Выбор настроения
- Карточка рекомендации
- Кнопка «Другой фильм»
- Заготовка кнопки «Смотреть позже»
- Фильм дня
