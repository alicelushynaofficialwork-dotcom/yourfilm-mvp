# Дорожная карта YourFilm

## Главная идея

YourFilm — это ИИ-платформа рекомендаций фильмов, где подбор строится не только по жанру, а по настроению, жизненной ситуации, цели человека и его эмоциональной потребности.

## Этап 1: Рекомендации по настроению

- Создать локальную базу фильмов.
- Добавить шесть стартовых настроений MVP.
- Подбирать фильм по выбранному настроению.
- Объяснять рекомендацию человеческим языком.
- Добавить действие «Другой фильм».

## Этап 2: Чат с имитацией ИИ

- Спросить пользователя о настроении.
- Спросить, что сейчас происходит в жизни.
- Спросить, чего пользователь хочет от фильма.
- Спросить, смотрит ли пользователь один или с кем-то.
- Сформировать более глубокую рекомендацию.

## Этап 3: Список «Смотреть позже»

- Сохранять фильмы в localStorage.
- Показывать сохраненные фильмы.
- Удалять фильмы из списка.
- Сохранять настроение, с которым фильм был добавлен.

## Этап 4: Обратная связь после просмотра

- Спросить, как пользователь чувствует себя после фильма.
- Спросить, помог ли фильм.
- Предложить похожий фильм или фильм под другое настроение.
- Использовать ответы для улучшения будущих рекомендаций.

## Этап 5: Аккаунт пользователя и персонализация

- Добавить регистрацию и вход в аккаунт.
- Хранить историю настроений, рекомендаций, сохраненных фильмов и обратной связи.
- Использовать собранные данные для более точных персональных рекомендаций.
- Сделать персональный чат с ИИ, который помнит предпочтения пользователя.
- Добавить настройки аккаунта.
- Добавить переключение темы интерфейса: темная и светлая тема.

## Этап 6: Главная страница с общими рекомендациями и рекламой

- Сделать главную страницу как открытую часть сервиса.
- Показывать общие рекомендации фильмов без глубокой персонализации.
- Добавить общего ИИ-помощника для пользователей без аккаунта.
- Добавить рекламные блоки на основной странице.
- Разделить опыт пользователя: гость видит рекламу и общие рекомендации, зарегистрированный пользователь получает персональные рекомендации.

## Этап 7: Подписка без рекламы

- Добавить месячную подписку по модели YouTube Premium.
- Дать подписчику использование аккаунта без рекламы.
- Сохранить доступ к персональному ИИ-помощнику и истории рекомендаций.
- Добавить страницу управления подпиской.
- Позже подключить платежную систему.

## Этап 8: Настоящий ИИ и API

- Подключить OpenAI API для анализа текста и объяснения рекомендаций.
- Подключить TMDB API для постеров, трейлеров, метаданных и рейтингов.
- Перенести пользовательские данные в Supabase.
- Использовать историю пользователя для персональных промптов и более точных рекомендаций.

## Ориентиры интерфейса

За основу удобства интерфейса брать лучшие паттерны известных кино-платформ:

- MEGOGO: понятная главная страница, категории, карточки фильмов, быстрый доступ к просмотру.
- Sweet.tv: удобная навигация, аккуратные подборки, понятные пользовательские сценарии.
- UAKino: быстрый поиск, простая структура каталога, фокус на доступности контента.
- HDRezka: привычная логика карточек, жанров, сезонов, поиска и похожих фильмов.

Важно: использовать эти сайты как ориентир по удобству и привычным пользовательским сценариям, но делать собственный визуальный стиль YourFilm.

## Будущие направления продукта

- Друзья и общие плейлисты.
- Психологический разбор фильмов.
- Разбор фильмов для режиссеров.
- Профориентация через фильмы.
- VR-кинотеатр.
- Персональные ИИ-фильмы по истории пользователя.
